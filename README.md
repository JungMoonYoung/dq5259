# 데이터품질검증-ISO/IEC 5259

ISO/IEC 5259 기반 AI 학습데이터 품질 평가 도구

> 표준을 번역하며 공부하고, 진단 도구를 시험하며 적용해 보니,
> ML 학습데이터에 꼭 필요한 품질 평가가 비어 있어서 직접 만들었다.

## 배경

1. **학습**: ISO/IEC 5259-2·3·5(분석·ML용 데이터 품질)를 국문 번역하며 측정값(Part 2)·관리 절차(Part 3)·거버넌스(Part 5) 체계를 익혔다.
2. **적용**: 업무에 도입된 상용 데이터 품질 진단 솔루션을 학습하고, 범용 진단(구문·참조·메타·파일명·통계)을 11종 포맷 시험 데이터로 직접 사용·검증했다.
3. **발견**: 5259-2와 대조하면, 범용 진단은 일반 데이터 품질(ISO/IEC 25024 계열)에 집중한다. 5259-2가 **ML용으로 새로 정의한 특성**(균형·다양성·식별가능성·유사성)은 다루지 않는다.
4. **구현**: 그 빈 곳을 5259-2 측정값으로 직접 구현하고, 5259-3의 확인 검토(6.3.9)와 기준값·기록 요구(6.3.10, 6.4)대로 판정·기록하는 도구를 만들었다.

## 표준 조항 ↔ 구현

| 5259 조항 | 요구 내용 | 구현 |
|---|---|---|
| 5259-3 6.3.9 | 데이터 제공 이전, 5259-2 측정값으로 품질 확인 | 학습 전 게이트 → 본 평가 판정 (`runner.run()`) |
| 5259-3 6.3.10 c | 측정값 식별 | `runner.select()` 데이터 유형별 적용/미적용 + 사유 |
| 5259-3 6.3.10 b | 기준값 문서화 | YAML 설정의 `threshold`·`direction` |
| 5259-3 6.4 d, e | 사용 측정값·기준값 기록 | 보고서 + `runs/run_*.json` 실행 이력 |
| 5259-2 6장 | 측정 함수 | `dq5259/measures/` — QM ID별 함수 |
| 5259-2 8장 | 데이터 품질 보고 | 시험성적서 형식 HTML 보고서, 결함 CSV |

## 측정값

**사전 점검** — 평가 가능한 상태인지 확인 (범용 진단 영역이라 최소 구현)

| ID | 측정값 | 측정 함수 | 기본 기준 |
|---|---|---|---|
| Com-ML-5 | 라벨 완전성 | X = A/B (A: 라벨 없거나 불완전한 샘플, B: 전체 샘플) | ≤ 0.01 |
| Com-ML-3 | 특성 완전성 | X = A/B (특성별 null 아닌 항목 / 전체 항목), 최솟값 | ≥ 0.99 |
| Con-ML-1 | 레코드 일관성 | X = A/B (A: 중복 레코드, B: 전체 레코드), SHA-1 | ≤ 0.01 |

**본 평가** — ML 전용 품질 특성 (5259-2 6.5절)

| ID | 측정값 | 측정 함수 | 기본 기준 |
|---|---|---|---|
| Bal-ML-3 | 범주 간 균형 | X = A/B (A: 평균 범주 크기, B: 평균과의 최대 절대 차이) | ≥ 0.5 |
| Bal-ML-8 | 라벨 분포 균형 | X = JSD(실제 분포, 균일 분포), 밑 2 | ≤ 0.3 |
| Bal-ML-1 | 밝기 균형 | X = A/B (A: 평균 밝기, B: 최대 절대 차이) | 정보 제공 |
| Bal-ML-7 | 라벨 비율 균형 | X = 두 그룹 간 라벨 L 비율 차이의 최댓값 | ≤ 0.1 |
| Div-ML-3 | 범주 크기 다양성 | X = A/B (A: 기준 미만 범주 수, B: 전체 범주 수) | ≤ 0.2 |
| Idn-ML-1 | 식별가능성 비율 | X = A/B (A: 단독·결합으로 식별 가능한 레코드, B: 전체) | = 0 |
| Sim-ML-1 | 샘플 유사성 | X = 1 − B/A (A: 샘플 수, B: 군집 수) | 정보 제공 |
| Con-ML-2 | 데이터 라벨 일관성 | X = A/B (A: 동일 라벨인 유사 항목 쌍, B: 유사 항목 비교 쌍) | ≥ 0.9 |
| Sim-ML-3 | 샘플 독립성 | X = A/B (A: 분산 95%를 설명하는 PCA 주성분 수, B: 전체 차원 수) | 정보 제공 |
| Bal-ML-2 | 해상도 균형 | X = A/B (A: 평균 해상도, B: 최대 절대 차이) | 정보 제공 |
| Div-ML-1 | 라벨 풍부도 | X = A/B (A: 고유 라벨 수, B: 데이터 항목 수) | 정보 제공 |

### 구현 해석 (표준이 구체적 방법을 정하지 않은 부분)

- **Idn-ML-1**: '단독으로' 식별 → 직접식별자 13종 정규식(주민·외국인등록번호, 여권, 면허, 카드, 계좌, 건강보험, 휴대·일반전화, 이메일, 법인·사업자번호) + 이름 필드. '결합하여' 식별 → 준식별자 조합의 동일 집단이 k명 미만(k-익명성 위반).
- **Sim-ML-1**: 측정 함수 수식 대신 비고 7("샘플 수 = 군집 수이면 0")에 맞춰 X = 1 − B/A로 해석. 군집화는 이미지 dHash(16×16, 256비트)의 해밍 거리 ≤ 24를 같은 군집으로 묶는 방식(Union-Find). 기준은 실데이터로 보정했다 (아래 '실데이터 적용').
- **Bal-ML-7**: 모든 라벨 L과 그룹 쌍 중 비율 차이가 가장 큰 값을 대표값으로 보고.
- **Con-ML-2**: '유사한 항목'을 데이터 유형별로 정의. 음성·텍스트는 같은 문장(`similar_key`)의 발화끼리, 이미지는 dHash 해밍 거리 ≤ h인 쌍끼리 비교하고, 이미지의 라벨은 범주 집합으로 본다.
- **Sim-ML-3**: 비고 1에 따라 열 평균을 빼고 행 크기를 1로 정규화한 뒤 PCA. 이미지 특징은 8×8 흑백 축소(64차원). 샘플 수가 차원보다 적으면 A의 상한이 (샘플 수 − 1)임을 보고서에 표기.
- **기준값**은 예시이며 사용 목적에 맞게 조정해야 한다 (5259-3 6.3.10 b). 목적에 따라 기준이 크게 달라지는 측정값은 판정하지 않고 정보만 제공한다.
- 5259-2가 ISO/IEC 25024를 참조만 하는 측정값(Con-ML-3 등)은 구현하지 않았다.

## 실데이터 적용 (AI Hub, 2026-10-29)

본인 계정으로 내려받은 AI Hub 공개 데이터에 적용했다. 원본 데이터는 재배포 금지라 저장소에 포함하지 않는다.

### 배송로봇 비도로 운행 데이터 — Validation 2D 실환경 (이미지 16,000장, 객체 283,008개)

| 측정값 | 결과 | 해석 |
|---|---|---|
| 사전 점검 3종 | 통과 | 이미지-라벨 16,000쌍 모두 일치, 누락·중복·읽기 실패 0 |
| Bal-ML-3 범주 균형 | **0.29 미충족** | vegetation 56,985개 vs twowheeler 292개 (약 195배). 신호등 324·교통표지 782 등 안전 관련 범주가 적다 |
| Bal-ML-7 환경별 비율 | 28.4%p 미충족 | 공원 vegetation 30.3% vs 식당 1.9%. 차이 자체는 환경 특성이고, 핵심은 실내(홀·식당) 객체가 전체의 약 2%뿐이라는 환경 쏠림 |
| Bal-ML-2 해상도 | 4종 혼재 | 2592×2048 50%, 1280×720 25%, 1920×1080 24%, 2048×1536 1% — 카메라별 차이, 리사이즈 정책 필요 |
| Sim-ML-1 유사성 | 0.026 | 거의 같은 사진이 적다. 공원 cam04에서 311장 군집 1개 — 육안 확인 대상 |
| Idn-ML-1 | 0 | 직접식별자 없음 |

### 감정이 태깅된 자유대화(성인) — 라벨 11,023개, 발화 약 332만 건 (라벨 전용 모드)

| 측정값 | 결과 | 해석 |
|---|---|---|
| Com-ML-5 | 13건 | 대화 내용이 비어 있는 라벨 |
| Bal-ML-8 | 0.06 충족 | 긍정 62% · 중립 22% · 부정 17% |
| Bal-ML-7 성별 | 3.8%p 충족 | 다만 여성 화자 발화가 남성의 약 3.7배 |
| Idn-ML-1 | **0.95% 미충족** | 성별·연령·거주지·직업 조합이 5명 미만인 화자 포함 레코드 105건 |
| Con-ML-2 라벨 일관성 | **0.64 미충족** | 같은 문장(10자 이상)인데 감정이 다름. 예: "안녕하세요 반갑습니다" 387건 중 부정 41건, "오늘 대화 즐거웠습니다" 120건 중 부정 21건 |

### 실데이터에서 드러난 한계와 보정

1. **유사 이미지 판별 기준**: 합성 데이터 시험은 통과했지만, 실제 거리 사진에서 8×8 dHash(64비트)는 '위는 하늘, 아래는 바닥' 구도만 같아도 같은 지문이 나왔다. 약 1억 쌍을 비교한 실측에서 다른 장소 사진을 유사로 오판한 쌍이 16,838개(정밀도 약 1.6%)였다. 16×16(256비트)·거리 ≤ 24로 바꾸자 오판이 1쌍으로 줄었다.
2. **라벨 일관성의 비교 대상**: 처음에는 불일치의 대부분이 "음", "어", "네" 같은 추임새였다. 추임새는 맥락에 따라 감정이 달라지는 것이 정상이므로 10자 이상 문장만 비교하고, 문장부호 차이는 같은 문장으로 보도록 보정했다.
3. **다중 객체 이미지의 라벨 일관성**: 한 장에 객체가 평균 18개라, 유사 이미지끼리 범주 집합이 완전히 같아야 일치로 보는 기준은 과도하게 엄격했다(일치율 9%). 이 데이터에서는 판정하지 않고 정보로만 제공한다.

## 사용법

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

# 결함을 심은 합성 데이터 생성 + 진단
.venv\Scripts\python tools\make_synthetic.py
.venv\Scripts\python -m dq5259 configs\synthetic_robot.yaml --out runs\robot

# 화면
.venv\Scripts\streamlit run app.py
```

실제 데이터는 AI Hub에서 본인 계정으로 내려받아 `data/robot`, `data/emotion`에 둔다. 설정은 `configs/aihub_*.yaml`을 쓴다.
**AI Hub 데이터는 재배포가 금지되어 있어 저장소에 포함하지 않는다.**

### 설정에서 라벨 구조 지정

```yaml
fields:
  empty_check: annotation                 # 비어 있으면 불완전 라벨
  categories: annotation[].class_type     # 범주 라벨 ([]는 배열 펼치기)
  required: [info.time, info.weather]     # Com-ML-3 대상
  unit_items: Conversation[]              # Bal-ML-7 비교 단위
  unit_label: SpeakerEmotionCategory
  unit_group: ^{SpeakerNo}.Gender         # ^ = 루트 기준, {필드} = 항목 값으로 치환
  person_items: [Speaker1, Speaker2]      # Idn-ML-1 사람 정보
  quasi_identifiers: [Gender, Age, Residence, Occupation]
```
